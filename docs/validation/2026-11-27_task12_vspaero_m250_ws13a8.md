# Task 12: VSPAERO neutral point of the W/S 13 A 8 baseline, wing and tails only (owner ruling G-8)

Owner ruling G-8 (`docs/specs/00_decisions.md`): VSPAERO's wing-and-tail neutral point is quoted in Gate B **without the fuselage**, with that limit stated. Ruling B-2c makes W/S 13, A 8 the baseline, so the run is repeated on it.

**The limit, stated plainly.** This model has **no fuselage**. The fuselage's destabilising pitch moment is missing from the VSPAERO numbers, so **the VSPAERO static margin is expected to read high**. It is **not an independent fuselage-inclusive neutral point** and does not close R13. Evidence class: partly independent (a second lattice code on the same layout and the same CG; no fuselage).

Numbers are from `runs/task12/openvsp/2026-11-27_m250_ws13a8_vspaero/results.json` (script `conceptual/vspaero_check.py` with `--no-fuselage`, commit `2964a2b` at run time with a clean tree; OpenVSP 3.57.1, VSPAERO v.7.2.2, Python 3.12.3, seed none). Model: `runs/task12/openvsp/2026-11-27_m250_ws13a8/m250_ws13a8.vsp3`, built from `runs/task12/stage3/2026-11-26/m250_bands_cells/ws13_a8/design_pusher.json` (command in the folder's `model.json`). Settings as in the earlier wing-and-tails runs, no change: thin vortex lattice, default wake, alpha -2 to 8 deg (6 points), ISA 20,000 ft, loiter Mach 0.1420 and cruise Mach 0.2104 (from the record's mission), moments about the record's CG, mesh levels L1 (wing 352, wing + tails 896 panels) and L2 (1,472 and 3,712 panels). Cases run: wing L1/L2, wing + tails L1/L2; all four passed the validity gate. Reference: S 270.56 ft^2, MAC 6.094 ft, span 46.52 ft (A 8.00), CG at x = 11.938 ft (full fuel), 12.091 ft (empty). Quantities below are at the loiter Mach; the cruise Mach moves them the same way (`results.json`).

The model limits of the earlier VSPAERO reports apply unchanged: display airfoils (NACA 4415 / 0012), inviscid lattice, no propeller, turret or sponsons, no fuselage.

## How to read it for Gate B

- VSPAERO wing + tails puts the full-fuel margin at 0.145 to 0.154 MAC and the empty margin at 0.120 to 0.129, with the neutral point 0.20 to 0.25 ft aft of Stage 1's. R13's band is 5 to 15 % MAC at full fuel: L1 is inside the band, L2 is 0.004 above its upper end. Both are without a fuselage and are expected to read high. Stage 1's own equation with the fuselage term dropped gives a neutral point 0.099 ft aft of the with-fuselage value, which is about half of the L1 offset (0.097 of 0.196 ft) and 0.153 of 0.252 ft at L2.
- What it does show: a second code (vortex lattice with its own downwash), with the fuselage omitted, puts the wing-and-tail neutral point 0.1 to 0.15 ft aft of Stage 1's own no-fuselage-term neutral point, never forward of it. What it cannot show: the margin with the fuselage. R13 stays open for a fuselage-inclusive independent estimate.
- The model, conditions and mesh levels were fixed by the earlier runs; nothing was tuned for this one.
