# Task 12: M250-B17F altitude and relight (R6), source note (2026-11-24)

Owner ruling R-f (Éder, 2026-11-24): the M250-B17F engine's maximum operating altitude and its in-flight
relight envelope are **declared design assumptions**. No public source gives either one. No document
text is copied here, only values and citations. No run was made for this note and no report was
regenerated; the Stage 1 R6 rows still say "no source".

## Airframe limits (cross-references only, not engine limits)

| Airframe, engine | Altitude | Source |
|---|---|---|
| SF600A, 2 x 250-B17F/1 | 20,000 ft | EASA TCDS EASA.A.608 Issue 3 (01 Aug 2023), item 11, p. 11; FAA TCDS A61EU Rev 4, p. 5 |
| SF600, 250-B17C | 20,000 ft | EASA.A.608 Issue 3, p. 5 |
| SF260TP, 250-B17D | 20,000 ft | EASA TCDS EASA.A.586 Issue 03 (01 Feb 2017), Section G item 11, p. 22 |
| Nomad, 250-B17B/C/E | 25,000 ft, oxygen-limited | FAA TCDS A7PC Rev 6 |

**The 23,000 ft ceiling requirement is above every certified B17 installation found at 20,000 ft.**
The Nomad, at 25,000 ft, uses other B17 variants (B/C/E), not the B17F.

## Searched and found empty (do not repeat)

- FAA engine TCDS E10CE Rev 15: no altitude or relight entry.
- EASA: no B17 engine TCDS. EASA.IM.E.052 Issue 2 covers the 250 Series II, not the B17.
- UK CAA engine product list: points the B17 models to FAA E10CE.
- BN2T: EASA IM.A.388 Issue 4 and UK.TC.A.00042 Issue 5 give no altitude; both refer to Flight Manual
  FM/400, which is not public.
- Relight: no envelope in any FAA, EASA or UK TCDS; the TCDSs point only to non-public AFMs.
