# Task 12: lightest pusher that passes Gate B robustness (photo-scaled TP100)

Generated by `measurement/robust_sizing.py` from `sweep.json`; every number is from that run.

**The engine is hypothetical.** No turboprop of these powers with the TP100's table is known; the PBS brochure has none above 241 hp. The engine is the TP100 table scaled in power by P/241 (same lapse, part-power SFC curve, 5 % SFC allowance) and in weight by Raymer Table 10.3, W = 135.8 (P/241)^0.803. The result says which power class to look for, not that it exists.

## Method

- Candidates: P in [300.0, 330.0, 360.0, 400.0, 450.0] hp, W/S in [11.0, 13.0, 15.0, 17.0], A in [8.0, 10.0, 12.0, 14.0]; per P the lightest candidate with no failed Stage 1 compliance row is refined at +-1 in W/S and A (8 neighbours, one pass).
- Each candidate is sized for the smallest loiter time L_sized in [8, 16] h (bisection, 0.05 h) at which the built aircraft (wing area fixed, W0 = We(theta*) + payload + fuel) flies at least 3.5 h at the design corner theta*; not flyable counts as 0 h.
- theta* of iteration 1 is the h = 1 worst R5 point of `runs/task12/stage3/2026-11-22/rubber/P360/info_gap.json`. After the lightest design is picked the full corrected `info_gap.study` runs on it; if the R5 guarantee or R7 has h_hat < 1 its worst R5 point at h = 1 becomes theta* and the search is repeated once.
