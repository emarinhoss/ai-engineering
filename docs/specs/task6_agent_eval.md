# Task 6 spec: agent-layer evaluation and fault injection (planned Day 10, started Day 1)

Implements: Sonnet 5.5 (fault harness, fixes, tests). Fable 5.1 writes the transcript narrative and
reviews. Depends on: Task 3 code (queue, worker, MCP tools), tests/fake_su2.py.

## Goal

Show, with evidence in the repository, that the agent layer is "tools plus gates plus logs": every
bad input is stopped before SU2 runs, every solver failure is recorded with a reason, and the LLM
never chooses a sampling point. Claims stay modest.

## Deliverables

1. `tests/test_faults.py`: one test per injected fault, each asserting which layer caught it and
   what the user sees:
   - F1 schema: theta2 = 20 (above the bound) -> validate_config stage "schema", nothing written.
   - F2 physics gate: 12/14 (total turning 26) -> stage "gates", message names gate 4 and 24 deg.
   - F3 inverted mesh: monkeypatch the quality to report n_inverted = 1 -> stage "mesh_quality",
     nothing written.
   - F4 malformed config: a template with an unknown SU2 key -> stage "config_keys" names the key.
   - F5 solver divergence: fake SU2 with FAKE_SU2_NAN -> worker flags 2-failed reason "nan",
     convergence.status "diverged", history kept.
   - F6 solver crash: fake SU2 exit code 3 -> reason "nonzero_exit", log tail in error.json.
   - F7 timeout: FAKE_SU2_SLEEP > timeout -> reason "timeout", process group killed.
   - F8 killed worker: kill -9 mid-run, restart with stale heartbeat -> job re-run once, finished
     jobs untouched (already in test_worker_resume; reference it, do not duplicate).
   - F9 tampered job (mesh fingerprint edited) -> "mesh_mismatch", SU2 never started.
   - F10 result tampering: ingest_result with a result whose case_id or fingerprint does not match
     -> rejected, nothing stored.
   Each test writes one line to a list that a final test dumps as `docs/faults/fault_matrix.md`
   (fault, injected how, caught by, user-visible message) so the slide is generated, not typed.
2. Fixes: `tests/fake_su2.py` writes a physically consistent surface (p from the conservative
   variables equals the Pressure column; nodes on the mesh body marker) so `metrics.compute`
   succeeds on fake runs and the worker end-to-end test no longer needs a wrapper;
   `postprocess/surface.py` cross-check distinguishes "solution diverged" (non-finite values, or
   pressure above 1e7 Pa, or density above 100 kg/m^3) from a units mismatch in its error text.
3. `docs/faults/README.md` (short): how to re-run the matrix and what each layer is.

## Acceptance

- All F-tests pass without SU2; `docs/faults/fault_matrix.md` regenerated by the test run and
  committed; the worker end-to-end tests pass with the fixed fake solver; the validation report
  on the 12/14 records now says "solution diverged" instead of "check the units".
- A real failure documented end to end (PLAN Task 6 acceptance): the 12/14 divergence already
  recorded in runs/dev (root cause: non-steady laminar separation at 26 deg total turning; guard:
  gate 4) is referenced in the README.
