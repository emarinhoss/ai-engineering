# Fault injection: what stops a bad input or a failed run

The agent layer is tools plus gates plus logs. This folder shows, with tests that run without SU2,
which layer catches each fault and what the user sees. The LLM chooses no sampling point and edits no
job file; it moves JSON between the MCP server, Drive and the worker.

Re-run the matrix (no SU2 needed, about 10 s):

    python -m pytest -q tests/test_faults.py

This rewrites [fault_matrix.md](fault_matrix.md); commit the result. Run the whole file: if a fault
test is missing from the run (for example with `-k`), the last test skips and leaves the committed
matrix alone. The rows are generated by the tests, not typed.

## The layers, in the order a job meets them

1. **Schema** (`mcp_server/schemas.py`): types and bounds of every parameter. Stage `schema`.
2. **Physics gates** (`physics/gates.py`, five gates of `docs/specs/01_interfaces.md`): attached shocks,
   shock on lip, duct height, total turning at most 24 deg, wall-cell Reynolds number. Stage `gates`.
3. **Mesh quality** (`worker/make_case.py`): inverted cells, minimum angle, first-cell height, growth,
   aspect ratio. Stage `mesh_quality`.
4. **Config keys** (`cases/check_keys.py`): every key of `case.cfg` must exist in the pinned SU2
   v8.2.0 template. Stage `config_keys`.
   Layers 1 to 4 run in `validate_config` and again in `create_case`; a failure writes nothing.
5. **Worker checks** (`worker/run_worker.py`), before SU2 starts: the worker regenerates mesh and
   config from `params`, and compares `mesh_fingerprint` and `config_sha256` with the job file. A
   mismatch is `mesh_mismatch` or `config_mismatch`; SU2 is not started.
6. **Worker failure records**, after SU2 starts: `timeout` (process group killed), `nonzero_exit`
   (log tail kept), `nan` (diverged residual, history kept), `postprocess_error`. Each writes
   `error.json` with a reason and flags `2-failed`. A worker killed mid-run is found by its stale
   heartbeat and the job is re-run once (F8).
7. **Ingest checks** (`mcp_server/queue.py`, `ingest_result`): the result must carry the staged
   `case_id`, `mesh_fingerprint`, `config_sha256` and params. A bad result is refused and nothing
   is stored. A diverged or timed-out run must be reported with `ingest_error`.
8. **Postprocess checks** (`postprocess/surface.py`): "solution diverged" when the surface file has
   a non-finite value, pressure above 1e7 Pa or density above 100 kg/m^3; "check the units" only
   when a finite, sane state disagrees with SU2's own pressure or Mach column.

## Faults tested

F1 schema, F2 physics gate, F3 inverted cell, F4 unknown SU2 key, F5 solver divergence, F6 solver
crash, F7 timeout, F8 killed worker, F9 tampered job, F10a and F10b tampered result. F8 is run by
`tests/test_worker_resume.py` (it starts a subprocess and kills it); `tests/test_faults.py` only
checks that this test exists and quotes the worker's message.

The faults are injected through the fake solver `tests/fake_su2.py` and by monkeypatching, so the
matrix shows that the gates and records work. It does not show that real SU2 fails in these ways;
only F2 and F5 have a real counterpart (below).

## One real failure, end to end

The inlet at theta1 = 12 deg and theta2 = 14 deg (26 deg total turning) was run with SU2 v8.2.0 on
the medium and fine meshes, at two entropy fixes. The residual fell to about -7.5 by iteration 1200,
then grew and the run exited with an error (4347 iterations on the medium mesh). Records:
`runs/dev/2026-11-01_inlet_grid_study_ef03/` (cases `12_14_medium`, `12_14_fine`) and the diagnostics
in `runs/dev/2026-11-01_inlet_box_diagnostics/`.

- Diagnosis (recorded, not proven): theta2 = 14 deg alone converges (5/14 and 8/14 do), so the
  failure is the 26 deg total-turning corner. The residual pattern (falls to -7.5, then grows at
  any CFL) is that of a separation that does not settle to a steady state; the flow field was not
  inspected to confirm it.
- Guard: gate 4 (total turning at most 24 deg, trimmed from 26 on 2026-11-01), which F2 exercises:
  `theta1 = 12, theta2 = 14` is now refused at stage `gates` before any mesh is built.
- Postprocess: the saved surface file of the diverged run has pressures up to about 8e10 Pa and
  densities up to about 1e8 kg/m^3. The validation report (`python -m postprocess.report`) used to
  say "check the units" for it; it now says "solution diverged".
